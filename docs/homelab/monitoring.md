# Monitoring

This page documents dashboards, alerts, logs, and monitoring workflows.

## Monitoring Goals

- Know when services are down
- Know when containers restart
- Track resource usage
- Track useful alerts
- Reduce mystery failures

## Tools and Concepts

- Grafana dashboards
- Container logs
- Uptime checks
- n8n alerts
- Discord notifications
- Security Onion dashboards
