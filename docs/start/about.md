# About Me

I am a cybersecurity and IT operations leader with experience across enterprise communications, infrastructure support, technical troubleshooting, compliance workflows, operational planning, and team development.

My professional style is hands-on and practical. I like building systems that make work easier to understand, easier to repeat, and easier to improve.

## How I Work

| Principle | What It Means |
|---|---|
| Useful beats fancy | A tool should make the work easier, clearer, or more repeatable |
| Visibility matters | If you cannot see what is happening, you cannot manage it well |
| Documentation is part of the job | Good notes make systems easier to operate and rebuild |
| Automation should reduce noise | Alerts and workflows should help people act, not create more clutter |
| Technical work needs translation | Leaders need clear summaries, not walls of raw detail |
