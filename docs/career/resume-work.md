# Resume Work

## Purpose

This page tracks how technical work, leadership, and military experience are translated into civilian resume language.

## Resume Themes

- IT operations leadership
- Infrastructure management
- Cybersecurity operations
- Governance, risk, and compliance
- Project management
- Automation and process improvement
- Team training and mentorship

## Translation Pattern

| Military / Technical Work | Civilian-Friendly Framing |
|---|---|
| Watch floor operations | Operations center leadership |
| System troubleshooting | Enterprise IT issue resolution |
| RMF / ATO support | Security compliance and authorization support |
| Training Marines | Team development and technical mentorship |
| Infrastructure projects | IT project execution and stakeholder coordination |
