# Home Lab Operations

## Purpose

A self-hosted technical lab used for infrastructure, automation, cybersecurity, and application development projects.

## Problem

A home lab provides a safe place to build, test, break, and learn systems before applying the concepts in more serious environments.

## Approach

The lab focuses on repeatable infrastructure and practical services:

- Unraid server
- Docker containers
- Reverse proxy
- Monitoring dashboards
- Automation workflows
- Security monitoring
- Development projects
- Network troubleshooting

## Tools Used

- Unraid
- Docker
- Cloudflare
- Reverse proxy concepts
- Grafana
- n8n
- Security Onion
- Home Assistant
- Ubiquiti networking
