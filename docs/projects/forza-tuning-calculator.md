# Forza Tuning Calculator

## Purpose

A web-based tuning calculator and car database concept for racing game builds.

## Problem

Tuning cars manually can be time-consuming, especially when comparing different build types, power levels, weights, gear ratios, and car characteristics.

## Approach

The project explores a searchable car database and calculator workflow for:

- Drift tuning
- Drag tuning
- Grip tuning
- Electric vehicle tuning
- Car selection
- Gear visibility
- Build recommendations

## Tools Used

- Static web app concepts
- CSV data
- JavaScript
- Car database generation
- Local hosting
- Cloudflare / reverse proxy concepts

## Outcome

This project demonstrates web app planning, data normalization, UI iteration, and user-focused calculator design.

## Lessons Learned

- Data quality drives calculator quality.
- User input needs to match how people actually tune.
- A good calculator needs transparency, not just output numbers.
