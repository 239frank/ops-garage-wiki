# Security Onion Lab

## Purpose

A home lab security monitoring environment for learning network visibility, alerting, and SOC-style analysis.

## Problem

Cybersecurity theory is useful, but hands-on security monitoring requires real logs, real dashboards, real alerts, and real troubleshooting.

## Approach

The lab is designed to explore:

- Network security monitoring
- Log ingestion
- Detection workflows
- Alert triage
- Dashboard review
- Troubleshooting visibility issues

## Tools Used

- Security Onion
- Syslog
- Network traffic sources
- Lab network devices
- Virtual machines
- Home lab infrastructure

## Outcome

This lab shows security monitoring skills, network troubleshooting, and the ability to build a functional SOC-style learning environment.

## Lessons Learned

- Visibility problems are often network, firewall, routing, or ingestion issues.
- Monitoring is only useful when alerts are understandable.
- A small lab can still teach real detection and triage habits.
