# Domain Research Tools

## Summary

The Domain Research Tools project explores a repeatable way to find, evaluate, and organize domain name ideas.

The project is less about buying random domains and more about building a structured review process for availability, naming quality, use case fit, and decision-making.

## Problem

Domain research can become scattered across browser tabs, notes, availability checkers, pricing pages, and half-formed ideas.

A better workflow keeps the evaluation consistent so ideas can be compared instead of guessed at.

## Approach

The workflow is designed around repeatable evaluation:

1. Capture domain ideas.
2. Check availability.
3. Review naming quality.
4. Consider use case and audience.
5. Track pricing or acquisition notes.
6. Compare options using consistent criteria.
7. Keep the strongest candidates organized.
