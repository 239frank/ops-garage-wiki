# Personal Wiki Build

## Purpose

A public-facing technical wiki and portfolio built to document projects, lessons learned, and technical growth.

## Problem

Technical work gets lost when it only lives in chats, screenshots, folders, and memory. A personal wiki creates a durable place to document work and make it visible.

## Approach

The wiki is built as a static documentation site:

- Markdown-based pages
- Git-backed version control
- Cloudflare Pages hosting
- Project writeups
- Screenshot folders
- LinkedIn-friendly structure

## Tools Used

- MkDocs
- Material for MkDocs
- GitHub
- Cloudflare Pages
- Markdown
- PowerShell

## Outcome

This site becomes the central portfolio for technical projects, home lab work, automation, cybersecurity, and career transition documentation.

## Lessons Learned

- Documentation is easier when the structure already exists.
- A portfolio should explain the problem, not just show the tool.
- Public pages need sanitization before screenshots are posted.
