# Story: Compliance Work That Stays Reviewable

Compliance is full of repetitive coordination: asking for evidence, checking whether it supports a requirement, shaping a narrative, and preparing the next meeting. That is exactly where a careful copilot can help.

## Evidence Copilot

The Compliance Evidence Copilot is an offline browser demo for a client workflow. It guides intake, evidence requests, evidence review, narrative drafting, and meeting packets while keeping the process visible and separated by client.

It is not positioned as a free-roaming agent. It is a practical workflow tool with clear gates, evidence traceability, and human approval before anything becomes a client deliverable.

## Keri Program Builder

Keri is a local-first Windows trial for building a structured compliance program. It works with sanitized client workspaces, a control workflow, evidence cataloging, open-item pacing, meeting outcomes, and a POA&M-style follow-up record.

| Built for | Not designed to do |
|---|---|
| Organize a working compliance program | Upload client material to a cloud service |
| Keep evidence and open items visible | Make unchecked claims about control satisfaction |
| Prepare meetings and follow-up | Replace professional review |

The through-line is simple: put the paperwork in order so the people doing the work can make better decisions.
